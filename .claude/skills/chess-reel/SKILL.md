# Шахматный рилс — конвейер

Рабочая папка: `content-factory/`. Браузер: `CHROME=$(ls /opt/pw-browsers/chromium_headless_shell-*/*/chrome-headless-shell)`.

## Команды
- «сделай N рилсов» → `node batch.mjs <следующий_номер> N` (номер = число строк в data/ledger.csv). Отправь 1–2 файла автору на просмотр.
- «новый хук <текст>» → добавь в `hooks.json` (id латиницей). Плейсхолдеры: `{rating}`, `{moves}`.
- «разбери донора <ссылка/описание>» → запиши в `data/sources.json`, разложи: хук (0–3с), что в кадре, где удивление, CTA. Предложи 3 адаптации под шахматы. Новый формат = новая Composition в `src/`, не ломай PuzzleReel.
- «внеси статистику» → автор диктует просмотры, заполни ledger.csv (url, published, views_24h, views_7d…).
- «отчёт по рилсам» → `node economics.mjs <расходы$> <выручка$>`: лучшие хуки → размножить (тот же хук, новые задачи); слабые (< медианы через 7 дней) → выключить.

## Правила
1. Только правдивые хуки: рейтинг задачи реальный (из базы), никаких выдуманных «97%».
2. Польза внутри ролика: зритель получает задачу и решение, даже если не пишет в комментарии.
3. Сначала сильный результат, потом удешевление. Перемонтаж того, что залетело (новый хук/задача/порядок), — основной способ масштаба.
4. Первые публикации — вручную с телефона, неделя наблюдения на формат.
5. Никаких накруток, автоматических лайков/«прогрева» ботами и SIM-ферм — риск бана и закона.
6. Цвета бренда: #C9A84C, #2C241B, #F5EFE6.
