# Контент-завод: шахматные рилсы

## Как работает
- `src/PuzzleReel.tsx` — шаблон рилса 1080×1920, 15 сек, цвета платформы (#C9A84C золото, #2C241B тёмно-коричневый, #F5EFE6 крем).
- Источник задач: `../public/puzzles/tactical-storm.json` (999 задач с платформы) → отбор в `src/puzzles.json`.
- Структура: 0–2.5с ХУК (шок-цифра + тряска) → 2.5–8с таймер «найди ход» → 8–12с решение + вспышка «МАТ!» → 12–15с CTA.
- Рендер: `npm i && node batch.mjs 0 10` → `out/reel-0..9.mp4`. Один рилс ≈ 30–60 сек рендера → 60/день реально на одной машине.

## Конвейер (после эфира «Контент-завод»)
- `hooks.json` — библиотека хуков (A/B-тест). Хуки только правдивые: `{rating}` берётся из базы.
- `node batch.mjs <start> <count> [hookId]` → ролики + строка в `data/ledger.csv` (учёт публикаций).
- `node economics.mjs <расходы$> <выручка$>` → цена публикации, расходы/выручка на 1 млн просмотров, рейтинг хуков.
- `data/sources.json` — доноры форматов; `data/accounts.md` — карточки аккаунтов (без паролей).
- Скилл Claude Code: `.claude/skills/chess-reel` — фразы «сделай 10 рилсов», «разбери донора», «отчёт по рилсам».

Цикл: тренды (80% внимания) → формат → скилл → сильный ролик → неделя наблюдения → удешевить → перемонтаж победителей → масштаб.

## Стратегия (кратко)
1. **Неделя 1:** 3–6 рилсов/день, 5 хуков × разные задачи. Метрика — удержание первых 3 сек и досмотры, не лайки.
2. **Неделя 2–3:** победившие хуки ×10 вариаций; новые форматы: «Найди ошибку», «Ловушка за 3 хода», «Магнус vs ты», озвучка ElevenLabs.
3. **Масштаб 30→60/день:** авто-публикация через API (Instagram Graph, YouTube Data, TikTok Content Posting) или сервис (Metricool/Repurpose.io).
4. **Воронка:** CTA «пиши ЗАДАЧИ» → ManyChat/бот → Telegram-канал (прогрев) → дешёвый продукт (курс/подписка на платформу) → дорогие уроки.

## Что подключить позже

- Парсинг трендов (Apify / MCP) — раз в 2 дня топ шахматных рилсов → адаптация хуков.
