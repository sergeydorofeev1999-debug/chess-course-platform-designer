# Карта контента: боли начинающих → форматы

Источник задач: **база Lichess (CC0)** — `src/puzzles-lichess.json`, 5174 задачи, каждая сыграна 3000+ раз, популярность ≥ 90%.
Категории (`BUCKET=`): mateIn1, mateIn2, opening, fork, pin, sacrifice, smothered, queenSac, endgame. Обновление: `scripts/import_lichess.py`.
Плюс задачи платформы (`source: platform`) и ловушки/партии вручную (`data/lines.json`).

## Форматы (что можно выпускать)
| Формат | Удивление/хук | Производство | Статус |
|---|---|---|---|
| Рилс-задача с таймером | «Найдёшь мат за 5 с?» | Remotion, база задач | ✅ `batch.mjs` |
| Карусель 4 слайда | «Мат в 2 — найдёшь?» | Remotion still | ✅ `carousel.mjs` |
| UGC-реакция + задача | живое удивление 3 с | реакции креаторов + Remotion | ✅ шаблон `ugc.mjs`, ждём реакции |
| Ловушка / партия по ходам | «Мат за 2 хода», «Отдал ферзя и выиграл» | Remotion, `data/lines.json` | ✅ `LineReel` |
| Правило за 60 с | «Ты 100% не знал это правило» (взятие на проходе, рокировка, пат) | Remotion + озвучка | ⏳ |
| Мультгерой-тренер | персонаж объясняет как другу | Remotion + 1 раз нарисовать героя + голос | ⏳ |
| «Новичок vs …» / «ход, похожий на ошибку» | «Это ошибка?.. нет, гениально» | задачи sacrifice/queenSac | ⏳ (есть данные) |
| Легенды и истории | «12-летний обыграл чемпиона» | мульт/картинки + голос | ⏳ |
| Рилс-картинка | факт/совет одним кадром, 5 с | Remotion still → видео | ⏳ |
| Разбор партии ученика | реальный прогресс, кейс | запись экрана платформы + голос | ⏳ (нужны записи) |
| Челлендж «30 дней шахмат» | серия, возвращает зрителя | любой формат + номер дня | ⏳ |
| Аватар/твоё лицо в углу | доверие к тренеру | запись + клон голоса | ⏳ (нужны 8 мин записи) |

## Правило выбора
По каждой единице: какую боль из таблицы закрывает? понятна ли новичку без терминов? есть ли удивление в первые 3 с?
